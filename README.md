# Study Hub

Study Hub is a responsive React frontend for exploring self-paced learning paths in HTML, CSS, JavaScript, React.js, Node.js, Python, Git, and SQL. Course pages provide a topic outline and links to freely available learning references.

## Run locally

From this project directory:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`; to check the source with ESLint, run `npm run lint`.

## Project notes

- The course catalog and course details are frontend data; no account is required to explore them.
- Login and registration are interface previews. No authentication service is connected, and credentials are not transmitted or saved.
- The contact form validates required fields in the browser but does not send or store messages because no delivery service is configured.
- Learning references are maintained by their respective publishers. Study Hub does not offer paid courses, certifications, or claim partnerships.
